# 🧪 Cypress Autotests — Stack-IT Demo

Автоматизированные UI-тесты для тестового задания на позицию Инженер по автоматизации тестирования.  
Тестирование выполняется для демо-сайта:  
https://demo.app.stack-it.ru/fl/  

Инструмент автоматизации: Cypress

## 📌 Область тестирования

Раздел системы:  
Адресный фонд → Адреса проживающих  

Проверяется работа таблицы уровней адресов (CRUD операции).

## ⚙️ Установка проекта

```bash
git clone <repo_url>
cd <repo_name>
npm install
```
## ▶ Запуск тестов

GUI режим (рекомендуется):

```bash
npx cypress open
```

## 🏗 Стек технологий

- Cypress
