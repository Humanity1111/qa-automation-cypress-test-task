# 🧪 Cypress Autotests — Stack-IT Demo

Автоматизированные UI-тесты для тестового задания на позицию Инженер по автоматизации тестирования.  
Тестирование выполняется для демо-сайта:  
https://demo.app.stack-it.ru/fl/  

Инструмент автоматизации: Cypress

## 📌 Область тестирования

Раздел системы:  
Адресный фонд → Адреса проживающих  

Проверяется работа таблицы уровней адресов (CRUD операции) и стабильность формы авторизации.

## ✅ Реализованные автотесты

📁 `address.cy.js` — CRUD тесты

№ | Тест | Что проверяется  
--|------|----------------  
1 | Открытие диалогового окна | Кнопка "Добавить" открывает модальное окно  
2 | Добавление уровня «Район» | Создание новой записи и её появление в таблице  
3 | Редактирование записи | Изменение имени уровня  
4 | Удаление записи | Удалённая запись исчезает из таблицы  
5 | Валидация формы | Нельзя сохранить запись с пустым обязательным полем  

📁 `login-bug.cy.js` — фиксация дефекта  

Тест воспроизводит дефект, при котором поле "Логин" иногда отсутствует на странице авторизации.

## 🐞 Обнаруженный баг

Во время тестирования выявлен дефект UI.

**Проблема:**  
Иногда при загрузке страницы форма авторизации отображается некорректно — отсутствует поле ввода логина.

**Влияние:**  
- Невозможность авторизации  
- Падение автотестов  
- Нестабильность приложения  

Подробности описаны в `BUG_REPORT.md`.
